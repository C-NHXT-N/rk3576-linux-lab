# 课件模板

复制此结构编写新课，并替换占位说明。此文件不是可执行实验。

> 建议时间：20—40 分钟 · 状态：已编写/已验证/待验证
>
> 执行位置、Shell、账户、工作目录、先修链接、依赖。

## 这课完成什么

用“能解释/能完成/能定位什么问题”写两三个目标。

## 跟着做：解释、预测、操作、观察

每次先解释必要概念，提出预测，给出一小组命令，说明关键现象和可接受差异。遇到新概念链接主要讲解位置。

## 自己完成一次

给一个条件不同的任务与可观察结果，不提供逐字复刻步骤。

<details>
<summary>提示一：先想方向</summary>

给问题分解方向。

</details>

<details>
<summary>提示二：关键工具</summary>

给关键命令或接口，但保留必要思考。

</details>

<details>
<summary>参考思路与解释</summary>

解释为什么成立、如何验证，指出局限。

</details>

## 常见失败

按“现象 → 先检查 → 证据 → 下一步”组织，明确预期失败。

## 完成标准

- [ ] 可观察成果。
- [ ] 原因说明。
- [ ] 独立变式。

## 清理与回顾

列出本课创建的文件、进程和配置，以及具体清理方法。自评与程序检查分开。
