# 学习路线与建设状态

[课程目录](README.md) · [环境](environment.md) · [实测记录](validation.md)

## 主线与先修关系

```text
连接与编辑 → 文件与目录 → Shell 与文本 → 进程与系统观察
                                            ↓
                                  巡检、监控、网络、systemd
                                            ↓
                                     Linux 系统编程
                                            ↓
                                RK3576 硬件机制与输入检查
                                            ↓
                                  RKNN 转换与单图推理
                                            ↓
                                  静态图片工程化服务（相机为后续扩展）
```

新概念先在所属小课讲清，综合项目链接回顾，再增加新的应用深度。系统巡检最早从身份信息开始，在后续课程中逐步扩展，避免一次讲完所有领域。
